# 1.0.8

- 録画は、レンダリングされたプレビュー サムネイル、最初から再生するプレビュー、編集、プリセット、エクスポート、保存、ソース保存、およびドラフト アクションを備えたフローティング クイック アクション カードに仕上げることができます。
- カメラの背景の削除は、調整可能な縦スケールのアウトライン、シャドウ、フレーム プレビューを備えたキャッシュされたステッカー スタイルをサポートします。
- 外観設定では、エディター、インスペクター パネル、エクスポート サーフェス、記録ツールバー、ツールチップ、マテリアル プレビューをダーク、ライト、自動モード間で切り替えることができます。
- カメラ オーバーレイは、より多くのアスペクト比、インライン進行による背景の削除、透明なポートレート モード、パッケージ化されたカスタム画像の背景、およびすべてのカメラ クリップへのワンクリック設定のコピーをサポートしています。
- クイック アクション カードは、キャプチャの選択中に非表示になり、記録またはキャンセル後に戻り、アクティブな表示に従い、表示されているすべてのカードをクリックできるようにします。
- 透明なポートレート カメラ オーバーレイは正しくエクスポートされ、グラデーションの背景編集ではプレビューがすぐに更新され、手動ズーム アンカーは表示されたままになり、数値入力によるドラッグは画面の端全体で安定したままになり、購入画面は選択した外観に従います。

# 1.0.7

- キャプションは、プロバイダーとローカル モデルの文字起こし、編集可能な読み上げセグメント、キャプションごとの表示、プリセットに基づいたスタイル、およびクリーンなエクスポート背景をサポートします。

- カメラ オーバーレイは、調整可能なコーナーの滑らかさと、より柔らかい正方形のデフォルト スタイルをサポートします。
- エフェクト レイヤーには、エディタ全体で Annotation という名前が付けられるようになりました。
- エディタ設定では、アニメーション、キーボード、ビューティーがデフォルトで非表示になり、追加の非表示エントリが More の下に収集されるなど、機能エントリを並べ替えたり非表示にしたりできます。
- 録音は、有効な画面、マイク、システム オーディオ入力を待ってからメディアを書き込み、遅延オーディオ サイドカーはプレビュー、エクスポート、タイムライン クリップ、および波形で整列したままになります。
- 初期の録画失敗後のカメラのクリーンアップではクラッシュしなくなり、ストレージ容量が少ない書き込み失敗でも、明確な警告とともに回復可能なメディアが維持されます。
- 無効になったキーボード キーは、プレビューやエクスポートを含めてプロジェクトを再度開いた後も非表示のままになります。
- Project の開始とエクスポートでは、最初のビデオ フレームが確実にレンダリングされ、より深くズームした後、密なキャプションとタイムライン グループが正しく分離されます。
- タイムラインのホバー カーソル、スクラブ再生ヘッド、ズーム アンカーは、再生、ドラッグ、スクロール、ズーム中に安定したままになります。
- リモート キャプション トランスクリプションは、リクエスト サイズを削減し、プロバイダーのファイル サイズ制限を早期に達成するために、最適化された一時音声をアップロードします。
- カメラのオーバーレイ プレビュー、高密度のタイムライン トラック、キャプション セグメントの編集は、長時間録画でもより応答性が高くなります。

- ズーム トラック作成プレビューをクリックすると、ズーム クリップが作成されます。
- カーソル クリックの効果は、iPhone モックアップを回転させても整列したままになります。
- モックアップのエッジは、記録を上書きすることなく、細い隙間を隠します。
- カーソルのクリック効果はデフォルトでオフになっており、クリックされたカーソルはより明確に縮小されます。
- 記録されたカーソル形状は、サポートされていない形状についてはデフォルトのポインタにフォールバックするカスタム カーソル スタイルを使用して、より多くのシステム状態を保持します。
- 録音ツールバーは、デスクトップ スペースを切り替えた後、Dock、メニュー バー、ショートカットから確実に開き、オーディオのキャプチャと録音中にガラスと位置を維持します。
- ウィンドウ記録の選択では、クリック可能な Esc 終了コントロールを備えたコンパクトなツールバー プロンプトが維持されます。
- クリック音のプレビュー再生は、カーソル イベント履歴が密集している録音でも応答性を維持します。

- デフォルトのカメラ アニメーション設定では、よりスムーズなズームのために、より柔らかいスプリング プロファイルとより強力なモーション ブラーを使用します。
- プレビュー カメラ モーションは、エッジクランプされたズームインおよびズームアウト パスをまっすぐに保ち、正しいズーム中心からの方向性モーション ブラーを使用します。

- ソースのトリミング後も、カーソルの位置とカメラのフォーカスは一致したままになります。
- カメラのオーバーレイは、プレビュー再生中にフレームと同期したままになります。
- 記録停止はすぐに Process に切り替わり、ファイナライズをより長く存続させます。
- フローティング録画ツールバーは、録画中にデスクトップを切り替えても表示されたままになります。
- 録音ツールバーのオーディオメーターは、より明確なレベルの動きを示します。
- エリア キャプチャの選択は、フローティング録画ツールバーから確実に前面に表示されます。
- ウィンドウとエリア キャプチャの選択はセカンダリ ディスプレイで機能します。
- 画面録画の許可を拒否すると、エラーは表示されずに録画がキャンセルされます。
- キャプチャ選択コントロールは、ターゲット ホバー、メニュー バー ステータス メニューの更新、Dock からの再起動など、Intel TestFlight のクラッシュを回避します。

- タイムラインのスクラブや中断されたインタラクションによって、プレビュー再生がフリーズしたり、最後までジャンプしたりすることがなくなりました。
- タイムライン クリップのサイズ変更またはドラッグによって、クリップを取得するときに再生ヘッドがジャンプしなくなりました。
- プレビューのオーディオのミュートとボリュームのコントロールは同期を保ち、スムーズにアニメーション化し、元に戻す手順は追加されなくなりました。
- カラー ピッカーは、入力された 16 進値を受け入れ、色を調整している間、ドラッグ ハンドルを固定したままにします。
- インスペクターのラベルには画面とデバイスの用語が使用されており、サイズ プリセット ピッカーは他のメニュー コントロールと一致します。
- ツールチップは、レコーディング コントロール、インスペクター タブ、および元に戻す/やり直しのショートカットに表示されます。
- 透明なツールチップ素材により、白い背景でもホバーバブルが表示されます。
- エクスポートされた MP4 ビデオは、プレビュー互換の H.264 フレーム順序を使用し、検疫メタデータを回避し、通常速度のオーディオ タイミングを維持します。
- ソース解像度のエクスポート サイズ設定では、フレーム パディング、固定キャンバス サイズ、モックアップ サイズなどの最終プレビュー構成が使用されます。
- エクスポートされたキャンバスでは、ピクセルの丸めによって生じるエッジの黒いバーが回避されます。
- ディスプレイ モックアップのエクスポートでは、アニメーション壁紙とフレームの背景が画面フレーム内に正しくレンダリングされます。
- ラップトップのモックアップは、クリップ記録コンテンツを丸い画面の角にエクスポートします。
- モックアップ ズームは、拡大されたデバイスをキャンバスの端にスナップすることなく、ソースの端を越えたカーソルの動きに追従できます。
- 繰り返し記録されたクリップは、古い末尾フレームではなく、正しいソース フレームからエクスポートされます。
- 4K エクスポートは、3% 前後で停滞するのではなく、高解像度録画で確実に開始されます。
- アニメーション壁紙やカメラ オーバーレイを使用した長時間のエクスポートが 79% 付近で停止することがなくなりました。
- フルボリューム オーディオ エクスポートでは、オーディオの多重化中にファイル サイズが増大するのではなく、レンダリングされた H.264 ビデオのビットレートが維持されます。
- 録音、プレビュー再生、高解像度のエクスポート、および大きなキーボードのタイムラインでは、CPU とメモリの使用量が少なくなります。
- エディターの信号機ボタンは、全画面遷移中もネイティブの位置を維持します。
