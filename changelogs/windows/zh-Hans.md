# 1.0.12

<!-- highlights
- 应用内更新提醒与版本亮点
- 长项目编辑更流畅
- 改进截图选区和快捷操作
-->

- 应用内会提醒 Microsoft Store 更新，可在“设置 > 关于”中检查更新并查看新版亮点。
- 长项目编辑更流畅，预览更新、音频波形、光标切换和键盘轨道响应更快。
- 编辑器刷新时保留已输入的数值和未提交的摄像头调整，保存时可靠地包含最新编辑。
- 在冻结画面上使用与录制相同的浮层选择截图窗口和区域；松开鼠标即可截取区域，按 Escape 或右键可取消。
- 截图快捷操作卡片采用更平滑的圆角和更稳定的鼠标指针，使用菜单时卡片会保持展开。
- 编辑器在缩放显示器上以正确的默认尺寸打开，导出窗口切换阶段时保持居中。
- 界面文字和菜单跟随应用语言，字重显示更一致。
- 可从下次启动时的崩溃提示中直接发送已保存的崩溃报告。

# 1.0.11

<!-- highlights
- 逐词字幕，支持离线和云端识别
- 新增截图设置页和快门音效
- 可在应用内直接发送反馈
-->

- 可为录制内容生成逐词字幕：既可以在电脑上用本地 Whisper 模型完全离线生成（首次使用时下载），也可以用你自己的 API 密钥调用云端转录服务。
- 可在新的字幕轨道、字幕检查器或“编辑字幕”窗口中编辑字幕；选中一条字幕即可试听、查看波形，并调整单个词的时间。
- 字幕样式（包括模糊和玻璃背景）会显示在预览和导出中，预设现在也会保存字幕外观。
- 新增“截图”设置页，可设置快门音效、快捷操作卡片、复制后删除或关闭，以及临时截图单独的清理周期。
- 截取整个显示器时会播放快门音效并短暂闪屏；新增“打开截图工具栏”快捷键和托盘菜单项。
- 截图行为与 macOS 版一致：区域截图在松开鼠标时立即完成，显示器截图直接截取鼠标所在的显示器，文件名形如“截图 2026-10-23 14.30.00.png”。
- 截图快捷键不再默认绑定；设置中已保存的快捷键会保留。
- 可在应用内直接向开发者发送反馈。
- 欢迎导览最后会询问是否分享匿名使用数据。
- HDR 录制转换为 SDR 时会保留高光部分的颜色。
- 预览中经过变速的片段会继续播放声音。
- 在 macOS 上创建的项目，在 Windows 上保存后仍保留字幕和键盘数据。

# 1.0.8

<!-- highlights
- 全新录制工具栏，支持暂停
- 支持导出 GIF 和复制到剪贴板
- 后台导出更快，支持 HEVC
-->

- 录制工具栏全新设计，与 macOS 版一致：亚克力胶囊卡片、实时音量表、流畅的过渡动画，录制中可一键静音摄像头、麦克风、系统音频和键盘叠加层。
- 可从工具栏或托盘菜单暂停和继续录制，托盘菜单会显示当前录制状态。
- 显示器、窗口和区域录制使用更紧凑的选择栏；按 Enter 即可开始录制，窗口录制会显示应用图标和窗口标题。
- 摄像头改为原生录制，支持 OBS Virtual Camera；ScreenCam 只会录制你选择的摄像头，如果摄像头没有画面，录制中就会提示。
- 开始录制前会先完成 Windows 屏幕捕获授权，并可在设置中管理捕获权限。
- HDR 显示器上的 HDR 应用窗口会正确进行色调映射，捕获最高可流畅达到 60 fps，开销更低。
- 被录制的窗口关闭或音频设备断开时，录制会正常结束。
- 导出在后台进行，并显示可随时取消的进度指示。
- 可在导出窗口和快速导出中导出 GIF，或把结果复制到剪贴板。
- 导出更快，只需一次编码；“自动”编码使用 H.265/HEVC，可在“设置 > 导出”中设置默认编码，MP4 文件在线播放时能更快开始。
- 导出窗口采用 macOS 版的默认设置，剩余时间估算更稳定，取消后状态明确，默认文件名更易读。
- 导出、裁剪和预设确认对话框会在编辑器上方以独立窗口打开。
- 新增“文件”菜单，包含“打开最近项目”“重命名”“保存”和“另存为”，任务栏跳转列表中也会显示最近的项目。
- 可在设置中添加自己的壁纸图片。
- 可设置开机启动 ScreenCam，设置中新增“关于”页面。
- 时间轴改进：缩放片段右键菜单、更容易找到的“分割”操作、Ctrl+Y 重做，更多编辑可一步撤销。
- 键盘叠加层用文字标注 Windows 修饰键，不再出现幻影按键或重复按键。
- 编辑器、工具栏、导出和快捷操作已完整提供简体中文。
- 删除的草稿会移到回收站，下次启动时会提示发送已保存的崩溃报告。
- ScreenCam Pro 窗口全新设计，支持月度订阅用户以及 60 天、90 天和 180 天兑换码，并在设置中显示 Pro 剩余时间。
- 导出中的背景音乐保持同步，变速片段的声音会做时间拉伸。
- 编辑器打开更快、播放更流畅，关闭后会释放内存。

# 1.0.4

<!-- highlights
- 首次在 Microsoft Store 发布
- 录制显示器、窗口或区域
- 缩放、光标样式和 MP4 导出
-->

- ScreenCam Windows 版首次在 Microsoft Store 发布。
- 可录制整个显示器、单个窗口或指定区域，并同时录制摄像头、麦克风和系统音频。
- 可用缩放和 3D 空间缩放、光标样式和点击音效、键盘叠加层、标注、背景和壁纸、设备样机、背景音乐、裁剪、变速和预设编辑录制内容。

- 可将编辑后的录制内容导出为 MP4。
- ScreenCam Pro 解锁导出，可一次性购买、按月订阅或使用 30 天兑换码。
- 截图功能作为实验性功能在设置中提供。
